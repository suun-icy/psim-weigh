## 修复：打印纸张始终输出 A4（DEVMODE + 自定义预览窗体方案）

**状态**: ✅ 已完成

**前两次方案均失败**：
1. .NET PaperSize + QueryPageSettings + BeginPrint + StandardPrintController — 打印机驱动仍输出 A4
2. HTML 模板 + 浏览器打印 — 操作繁琐且效果不佳

**最终方案**：三个组件协同工作

### 组件1: PrinterNative.cs — DEVMODE 级纸张控制
通过 P/Invoke `GlobalLock` 直接修改打印机驱动的 DEVMODE 结构体：
- `dmPaperSize = DMPAPER_USER (256)` — 自定义纸张标识
- `dmPaperWidth = 2400` — 240mm × 10（十分之一毫米）
- `dmPaperLength = 931` — 93.1mm × 10
- `dmFields |= DM_PAPERSIZE | DM_PAPERWIDTH | DM_PAPERLENGTH` — 标记字段已修改
- 自动检测 ANSI/Unicode DEVMODE 格式

### 组件2: PrintPreviewForm.cs — 自定义预览窗体
替代 .NET 内置 PrintPreviewDialog（其内部打印按钮会重置纸张设置）：
- 内嵌 PrintPreviewControl 显示预览
- 自带"打印"/"打印设置"/"放大"/"缩小"/"关闭"按钮
- "打印"按钮：先调用 PrinterNative 修改 DEVMODE → 再设置 .NET PaperSize → 最后打印
- "打印设置"按钮：弹出 PrintDialog 选择打印机 → 重新应用纸张 → 刷新预览

### 修改文件
- `Services/PrinterNative.cs` — 新增，DEVMODE P/Invoke
- `Services/PrintPreviewForm.cs` — 新增，自定义预览窗体
- `Services/PrintService.cs` — 重写，对接 PrinterNative + PrintPreviewForm
- `Form1.cs` — 调用 `PrintPreview()`
- `print.cs` — 调用 `PrintPreviewWithPrinterDialog()`
- `QueryForm.cs` — 调用 `PrintPreviewWithPrinterDialog()`
