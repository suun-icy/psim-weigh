## 1、数据库概述

### 1.1 基本信息

| 属性 | 说明 |
|------|------|
| **数据库引擎** | SQLite 3 |
| **文件路径** | `{AppDomain.CurrentDomain.BaseDirectory}/Data/weigh.db` |
| **连接字符串** | `Data Source={path};Version=3;` |
| **初始化方式** | 首次运行时自动创建，无需人工干预 |
| **字符编码** | UTF-8（SQLite 默认） |

```

            │       └── 不存在 → Directory.CreateDirectory()
            │
            ├── 检查文件 weigh.db 是否存在
            │       └── 不存在 → SQLiteConnection.CreateFile()
            │
            ├── 建立连接
            │       │
            │       ├── CREATE TABLE IF NOT EXISTS WeighRecords (...)
            │       ├── CREATE TABLE IF NOT EXISTS Customers (...)
            │       ├── CREATE TABLE IF NOT EXISTS CargoTypes (...)
            │       │
            │       ├── CREATE INDEX IF NOT EXISTS IDX_PlateNumber
            │       ├── CREATE INDEX IF NOT EXISTS IDX_CreateTime

## 4、表结构详细设计

### 4.1 WeighRecords（称重记录表）

**用途**：存储每一次车辆称重操作的完整记录，是系统的核心业务表。支持两次称重法（毛重→皮重→净重）、业务类型分类、记录审核流程、修改历史追踪和打印上传状态管理。

**DDL 语句编号**：SQL-001

## 5、索引设计

### 5.1 索引清单

| 序号 | 索引名 | 所属表 | 索引字段 | 类型 | 创建语句 |
|------|--------|--------|----------|------|----------|
| 1 | `PRIMARY KEY` | WeighRecords | `Id` | 唯一索引（自动） | `Id TEXT PRIMARY KEY` |
| 2 | `PRIMARY KEY` | Customers | `Id` | 唯一索引（自动） | `Id TEXT PRIMARY KEY` |
| 3 | `PRIMARY KEY` | CargoTypes | `Id` | 唯一索引（自动） | `Id TEXT PRIMARY KEY` |
| 4 | `IDX_PlateNumber` | WeighRecords | `PlateNumber` | 普通索引 | `CREATE INDEX IF NOT EXISTS IDX_PlateNumber ON WeighRecords(PlateNumber)` |
| 5 | `IDX_CreateTime` | WeighRecords | `CreateTime` | 普通索引 | `CREATE INDEX IF NOT EXISTS IDX_CreateTime ON WeighRecords(CreateTime)` |
| 6 | `IDX_Status` | WeighRecords | `Status` | 普通索引 | `CREATE INDEX IF NOT EXISTS IDX_Status ON WeighRecords(Status)` |

### 5.2 索引使用场景

| 索引 | 触发 SQL | 场景 |
|------|----------|------|
| `IDX_PlateNumber` | SQL-013 | 按车牌号模糊搜索称重历史：`WHERE PlateNumber LIKE '%沪A12345%'` |
| `IDX_CreateTime` | SQL-015 | 按日期范围查询日报/月报：`WHERE CreateTime BETWEEN '2026-07-01' AND '2026-07-31'` |
| `IDX_Status` | SQL-012/014 | 筛选进行中/已完成/已取消记录（虽然没有直接 WHERE Status，但为未来扩展做准备） |

### 5.3 建议新增索引

| 优先级 | 建议索引 | 理由 |
|--------|----------|------|
| 高 | `WeighRecords(BusinessType)` | 按业务类型筛选（进厂/出厂） |
| 高 | `WeighRecords(Category)` | `GetWeighRecordsByCategory()` 频繁调用，目前全表扫描 |
| 中 | `WeighRecords(OperatorId)` | 按操作员统计工作量 |
| 中 | `WeighRecords(IsUploaded)` | 查询未上传记录进行批量同步 |
| 低 | `Customers(Name)` | 按名称查找客户 |
| 低 | `CargoTypes(Name)` | 按名称查找货物类型 |

    │
    ├── 紧急修改 → Temporary(1) → 后续补审
    │
    └── 标记废弃 → Invalid(2)
```

## 8、JSON 内嵌结构

### 8.1 ModifyHistory 字段

`WeighRecords.ModifyHistory` 字段存储 JSON 数组，记录该称重记录的所有修改历史。

#### JSON Schema

```json
[
    {
        "ModifyTime":    "2026-07-04 14:30:00",
        "ModifierId":    "user001",
        "ModifierName":  "张三",
        "FieldName":     "NetWeight",
        "OldValue":      "35.300",
        "NewValue":      "36.000",
        "Reason":        "称重设备校准后修正"
    },
    {
        "ModifyTime":    "2026-07-04 15:00:00",
        "ModifierId":    "user002",
        "ModifierName":  "李四",
        "FieldName":     "DriverName",
        "OldValue":      "王五",
        "NewValue":      "赵六",
        "Reason":        "司机信息录入错误"
    }
]
```

#### 字段结构

| JSON 字段 | 数据类型 | 对应实体属性 | 说明 |
|-----------|----------|-------------|------|
| `ModifyTime` | datetime string | `ModifyHistoryItem.ModifyTime` | 修改时间（`yyyy-MM-dd HH:mm:ss`） |
| `ModifierId` | string | `ModifyHistoryItem.ModifierId` | 修改人 ID |
| `ModifierName` | string | `ModifyHistoryItem.ModifierName` | 修改人姓名 |
| `FieldName` | string | `ModifyHistoryItem.FieldName` | 被修改的字段名（如 `NetWeight`） |
| `OldValue` | string | `ModifyHistoryItem.OldValue` | 修改前的值（转为字符串） |
| `NewValue` | string | `ModifyHistoryItem.NewValue` | 修改后的值（转为字符串） |
| `Reason` | string | `ModifyHistoryItem.Reason` | 修改原因说明 |

#### 序列化/反序列化

`WeighRecordModifyHistory` 类**自行实现了 JSON 序列化/反序列化**，不依赖 Newtonsoft.Json：

- **序列化** `ToJsonString()` — 手动拼接 JSON 字符串（使用 `StringBuilder.AppendFormat`）
- **反序列化** `FromJsonString(string)` — 手动解析 JSON（字符级遍历，深度计数法分割对象）
- 兼容 .NET 4.7.2，不依赖第三方 JSON 库

### 10.2 文件生命周期

| 阶段 | 操作 |
|------|------|
| **首次启动** | `Directory.CreateDirectory()` → `SQLiteConnection.CreateFile()` → 空数据库文件 |
| **首次使用** | `DatabaseHelper.Initialize()` → `CREATE TABLE IF NOT EXISTS` → 创建表结构 |
| **日常使用** | 直接连接读写，无需额外管理 |
| **备份** | 直接复制 `weigh.db` 文件即可（SQLite 单文件特性） |
| **迁移** | 新版本启动时 `CREATE TABLE IF NOT EXISTS` 自动补全新字段（不删除已有数据） |

### 10.3 连接管理

每个数据库操作使用独立的 `using` 模式：

```csharp
using (var conn = new SQLiteConnection(ConnectionString))
{
    conn.Open();
    // 执行操作...
} // 自动关闭连接
```

- **无连接池**：每次操作创建新连接（SQLite 单文件，连接开销小）
- **无长连接**：不存在连接泄漏风险
- **无事务管理**：单条 SQL 自动提交
