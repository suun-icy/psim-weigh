## 一、二期目标

以「车辆」为核心，建设完整的车辆档案管理、皮重登记、进出场记录、车辆统计等功能模块。在不改动一期称重/打印/查询核心流程的前提下，通过模块化扩展实现车辆全生命周期管理。

## 三、详细设计

### 2.1 车辆档案管理（P0）

**目标**：建立车辆基础信息库，作为后续所有车辆相关功能的基石。

**数据库变更**：
```sql
CREATE TABLE IF NOT EXISTS Vehicles (
    Id              TEXT PRIMARY KEY,
    PlateNumber     TEXT NOT NULL UNIQUE,   -- 完整车牌号（如"豫A12345"）
    Province        TEXT,                    -- 省份简称
    PlateCode       TEXT,                    -- 车牌号码部分
    VehicleType     TEXT,                    -- 车辆类型（货车/挂车/罐车/自卸车等）
    BrandModel      TEXT,                    -- 品牌型号
    RatedLoad       DECIMAL(18,2),           -- 核定载重(吨)
    CurbWeight      DECIMAL(18,2),           -- 整备质量(吨)
    OwnerName       TEXT,                    -- 车主姓名
    OwnerPhone      TEXT,                    -- 车主电话
    OwnerUnit       TEXT,                    -- 所属单位
    FuelType        TEXT,                    -- 燃油类型（柴油/汽油/电动/天然气）
    EmissionStandard TEXT,                   -- 排放标准（国四/国五/国六）
    RegisteredDate  DATETIME,               -- 注册日期
    Status          TEXT DEFAULT 'Active',   -- 状态：Active=正常, Frozen=冻结, Blacklisted=黑名单
    PhotoPath       TEXT,                    -- 车辆照片路径
    Remark          TEXT,                    -- 备注
    CreateTime      DATETIME DEFAULT CURRENT_TIMESTAMP,
    UpdateTime      DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX IF NOT EXISTS idx_vehicle_plate ON Vehicles(PlateNumber);
CREATE INDEX IF NOT EXISTS idx_vehicle_status ON Vehicles(Status);
```

**新增文件**：
- `Models/Vehicle.cs` — 车辆实体模型
- `Forms/VehicleForm.cs` + `.Designer.cs` — 车辆档案管理窗口（列表+增删改查）
- `Database/VehicleRepository.cs` — 车辆数据访问层（按 Interface 设计）

**功能要点**：
- 车辆档案 CRUD（增删改查），支持按车牌模糊搜索
- 车辆列表分页展示（车牌、类型、载重、车主、状态）
- 从称重记录导入车辆（一键将称重记录中的新车牌创建为车辆档案）
- 双击车辆可编辑详情
- 车辆状态管理：正常 / 冻结 / 黑名单

**与一期兼容**：
- 称重主界面（Form1）车牌输入保持不变，不强制绑定车辆档案
- 若输入车牌匹配车辆档案，自动填充车主、联系方式等信息

**测试方案**：
- 新增车辆后验证数据库写入
- 编辑车辆后验证字段更新
- 从称重记录导入验证无重复
- 冻结车辆验证状态变更

### 2.2 车辆皮重登记（P0）

**目标**：为车辆预设常用皮重值，称重时自动匹配，减少重复称量空车的操作。

**数据库变更**：
```sql
CREATE TABLE IF NOT EXISTS VehicleTareRecords (
    Id              INTEGER PRIMARY KEY AUTOINCREMENT,
    VehicleId       TEXT NOT NULL,           -- 关联 Vehicles.Id
    PlateNumber     TEXT NOT NULL,           -- 冗余车牌，加速查询
    TareWeight      DECIMAL(18,2) NOT NULL,  -- 皮重(kg)
    WeighDate       DATETIME,                -- 称重日期
    Source          TEXT,                    -- 来源（Manual=手动录入, Weigh=实际称重）
    OperatorName    TEXT,                    -- 操作员
    Remark          TEXT,                    -- 备注
    CreateTime      DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (VehicleId) REFERENCES Vehicles(Id)
);

CREATE INDEX IF NOT EXISTS idx_tare_vehicle ON VehicleTareRecords(VehicleId);
CREATE INDEX IF NOT EXISTS idx_tare_plate ON VehicleTareRecords(PlateNumber);
```

**新增文件**：
- `Models/VehicleTareRecord.cs` — 皮重记录模型
- `Forms/TareManageForm.cs` + `.Designer.cs` — 皮重管理窗口

**功能要点**：
- 为车辆手动录入皮重或从历史称重记录自动提取
- 每个车辆保留最新 N 条皮重记录，支持查看历史
- 称重时若车辆已有皮重且用户选择"使用预设皮重"，跳过空车称重
- 皮重列表支持编辑和删除

**主界面集成**：
- Form1 中检测当前车牌是否有预设皮重
- 若有，在称重按钮旁提示"使用预设皮重 XX kg"，用户可选择跳过空车称重

**测试方案**：
- 录入皮重后验证数据库写入
- 称重流程中验证预设皮重回填
- 删除皮重后验证称重恢复双次流程

### 2.3 称重记录关联车辆（P1）

**目标**：将已有的称重记录（WeighRecords）与车辆档案（Vehicles）关联，实现数据闭环。

**数据库变更**：
```sql
ALTER TABLE WeighRecords ADD COLUMN VehicleId TEXT;
```

**修改文件**：
- `Database/DatabaseHelper.cs` — SaveWeighRecord 写入 VehicleId
- `Form1.cs` — 保存称重记录时查找 VehicleId 并写入
- `QueryForm.cs` — 查询结果中显示车辆类型、车主等信息

**功能要点**：
- 称重保存时自动按 PlateNumber 匹配 Vehicles 表，写入 VehicleId
- 查询窗口（QueryForm）展示关联车辆信息（类型、载重、车主）
- 编辑窗口（RecordEditForm）支持重新关联车辆
- 提供"未关联车辆"的称重记录筛选

**兼容性**：
- VehicleId 为可空字段，已有称重记录不受影响

### 2.4 车辆进出场记录（P1）

**目标**：记录车辆每次进出场的时间、操作员、称重状态，形成完整的进出场日志。

**数据库变更**：
```sql
CREATE TABLE IF NOT EXISTS VehicleLogs (
    Id              INTEGER PRIMARY KEY AUTOINCREMENT,
    VehicleId       TEXT,
    PlateNumber     TEXT NOT NULL,
    Direction       TEXT NOT NULL,           -- In=进场, Out=出场
    LogTime         DATETIME NOT NULL,       -- 进出时间
    RelatedWeighId  TEXT,                    -- 关联的称重记录 ID
    GrossWeight     DECIMAL(18,2),           -- 进/出时的毛重
    TareWeight      DECIMAL(18,2),           -- 进/出时的皮重
    OperatorName    TEXT,                    -- 操作员
    GateName        TEXT,                    -- 道闸名称
    Remark          TEXT,                    -- 备注
    CreateTime      DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX IF NOT EXISTS idx_vlog_time ON VehicleLogs(LogTime);
CREATE INDEX IF NOT EXISTS idx_vlog_plate ON VehicleLogs(PlateNumber);
```

**新增文件**：
- `Models/VehicleLog.cs` — 进出场记录模型
- `Forms/VehicleLogForm.cs` + `.Designer.cs` — 进出场记录查询窗口

**功能要点**：
- 称重完成时自动写入一条"进场"和一条"出场"日志
- 进出场记录独立窗口：按车牌/日期/操作员筛选，Grid 展示
- 统计当前在场车辆数
- 支持导出进出场记录 CSV

**主界面集成**：
- Form1 底部状态栏显示"当前在场车辆: XX 辆"
- 右侧面板新增"进出记录"快捷按钮

### 2.5 车辆统计分析（P1）

**目标**：以车辆维度生成统计报表，包括称重次数、累计净重、平均净重、皮重变化趋势等。

**新增文件**：
- `Forms/VehicleStatsForm.cs` + `.Designer.cs` — 车辆统计窗口

**功能要点**：
- 按时间范围筛选
- 统计维度：称重次数、累计毛重/皮重/净重、平均净重
- 图表展示：车辆称重频次排行（Top20）、车辆类型占比饼图
- 使用 DataGridView 展示统计数据
- 支持导出统计结果 CSV

**技术方案**：
- 纯 SQL 聚合查询实现，不引入图表库
- 可使用 Chart 控件（System.Windows.Forms.DataVisualization）画简单柱状图
- 如 DataVisualization 不可用，用 DataGridView + 条形图文本实现

### 2.6 车辆与司机绑定（P2）

**目标**：建立车辆与常用司机的绑定关系，称重时自动回填司机信息。

**数据库变更**：
```sql
CREATE TABLE IF NOT EXISTS VehicleDrivers (
    Id          INTEGER PRIMARY KEY AUTOINCREMENT,
    VehicleId   TEXT NOT NULL,
    DriverName  TEXT NOT NULL,
    DriverPhone TEXT,
    IsDefault   INTEGER DEFAULT 0,       -- 是否默认司机
    FOREIGN KEY (VehicleId) REFERENCES Vehicles(Id)
);
```

**修改文件**：
- `Form1.cs` — 选择车牌后自动匹配默认司机

**功能要点**：
- 车辆档案编辑中可管理"常用司机"列表
- 每个车辆可设置一个默认司机
- 称重时选择车牌后自动填充司机

## 六、兼容性与风险

| 项目 | 说明 |
|------|------|
| 一期兼容 | 所有新增模块不修改称重/打印/查询核心逻辑，仅在 Form1 中增加可选集成点（预设皮重提示、自动关联等），默认关闭 |
| 手动模式 | 所有车辆功能在手动模式下同样可用（如手动录入车辆档案、手动登记进出场） |
| 数据库 | 仅新增表和列（VehicleId 可空），不修改已有字段名和类型 |
| Windows 7+ | 不引入 .NET Core/.NET 5+ 依赖，System.Windows.Forms.DataVisualization 为 .NET Framework 自带 |
