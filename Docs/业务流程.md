### 2.2 数据接收与解析

```mermaid
sequenceDiagram
    participant 仪表 as 地磅仪表
    participant 串口 as SerialPort
    participant 事件 as DataReceived 事件
    participant 解析 as 协议解析器
    participant UI as Form1 UI 线程

    仪表->>串口: RS-232 数据帧<br/>0x02 =0012345 0x03
    串口->>事件: 触发 DataReceived 事件<br/>(后台线程)

    事件->>事件: num = ReadBufferSize
    事件->>事件: received_buf = new byte[num]
    事件->>事件: receive_count += num

    事件->>UI: this.Invoke() 切换到 UI 线程

    UI->>UI: 判断显示模式

    alt HEX 模式 (radioButton2.Checked)
        UI->>UI: foreach byte → ToString("X2") + " "
        UI->>UI: sb.Append(hexString)
    else ASCII 模式 (默认)
        UI->>解析: firstByte = ReadByte()
        alt firstByte == 0x02 (STX)
            UI->>解析: 循环读取直到 0x03 (ETX)
            UI->>解析: received_buf[i] = byteData
        else 普通 ASCII
            UI->>解析: 直接处理 received_buf
        end
        UI->>解析: Array.Reverse(received_buf)
        解析->>解析: ASCII 解码
        解析->>解析: 提取 "=" 后面的数字
        解析->>解析: 去除前导零
        解析->>UI: textBox6.Text = "12345"
    end

    UI->>UI: textBox_receive.AppendText(原始数据)
    UI->>UI: label7.Text = "Rx: " + receive_count + "Bytes"

    Note over 仪表,UI: 每次串口有数据到达即重复此流程
```

## 3、用户登录流程

```mermaid
sequenceDiagram
    participant 操作员
    participant Form1 as Form1 主窗口
    participant Login as UserLogin 窗口
    participant HTTP as HTTPS.cs
    participant Server as 远程认证服务器<br/>localhost:9999

    操作员->>Form1: 点击"打印"按钮 (button7)
    Form1->>Form1: 检查 user.token

    alt token 为空或 null
        Form1->>Login: new UserLogin().ShowDialog()
        Login-->>操作员: 显示登录窗口

        操作员->>Login: 输入用户名 + 密码
        操作员->>Login: 点击"登录"按钮 (button1)

        Login->>Login: 校验用户名和密码非空
        alt 账户或密码为空
            Login-->>操作员: MessageBox "账户或密码为空"
        else 输入完整
            Login->>Login: 拼接表单数据<br/>"username=xxx&password=xxx"
            Login->>HTTP: HttppPost(url, loginInfo)

            HTTP->>Server: POST /ums/login<br/>Content-Type: application/x-www-form-urlencoded

            alt 网络失败
                Server-->>HTTP: 异常
                HTTP-->>Login: return "" (静默失败)
                Login-->>操作员: 无响应 ⚠️
            else 请求成功
                Server-->>HTTP: JSON 响应<br/>{code, data: {userId, userName, token, ...}}
                HTTP-->>Login: 返回 JSON 字符串

                Login->>Login: JsonConvert.DeserializeObject&lt;UserInfo&gt;(json)
                Login->>Login: 填充 user.cs 静态字段
                Note over Login,Server: user.userId = data.userId<br/>user.userName = data.userName<br/>user.token = data.token<br/>user.roleId = data.roleId<br/>user.roleName = data.roleName<br/>user.roleDescription = data.roleDescription

                Login->>Login: MessageBox.Show(响应内容)
                Login->>Login: this.Dispose()
            end
        end
    else token 已存在
        Form1->>Form1: 跳过登录，直接执行上传
    end

    Form1->>Form1: 继续 button7 后续逻辑<br/>(构造数据 → 上传至服务器)

    Note over HTTP,Server: ⚠️ 登录失败时无错误提示<br/>⚠️ SSL 证书验证被全局跳过
```

```mermaid
sequenceDiagram
    participant 操作员
    participant Form1
    participant Pms as PmsWeightinfo (DTO)
    participant HTTP as HTTPS.cs
    participant Server as PMS 服务器<br/>10.102.84.200:9999

    操作员->>Form1: 点击"打印"按钮 (button7)

    Form1->>Form1: 检查 user.token
    alt token 为空
        Form1->>Form1: 弹出 UserLogin 窗口
        Note right of Form1: 参见"用户登录流程"
    end

    Form1->>Form1: 判断进销类型
    alt radioButton3.Checked (购入)
        Form1->>Form1: cargoComeOut = false
    else radioButton4.Checked (销售)
        Form1->>Form1: cargoComeOut = true
    end

    Form1->>Pms: 构造 PmsWeightinfo 对象
    Note over Pms: ⚠️ 以下字段当前均错误地<br/>使用了 textBox1.Text (重车重量):<br/>cargoPlate = textBox1.Text<br/>roughWeight = double.Parse(textBox1.Text)<br/>tare = double.Parse(textBox1.Text)<br/>netWeight = double.Parse(textBox1.Text)<br/>psimType = textBox1.Text<br/>printCount = int.Parse(textBox1.Text)

    Form1->>Form1: 构造请求头
    Note over Form1: Authorization: user.token

    Form1->>HTTP: HttppPost(url, jsonData, "utf-8", "application/json", headers)

    HTTP->>HTTP: url.StartsWith("https")? → 跳过 SSL 证书验证

    HTTP->>Server: POST /pms/weightinfo/addWeightinfo
    Note over HTTP,Server: Body: JSON 序列化的 PmsWeightinfo

    alt 网络异常
        Server-->>HTTP: 异常
        HTTP-->>Form1: return "" (静默失败)
    else 请求成功
        Server-->>HTTP: 响应结果
        HTTP-->>Form1: return result
    end

    Form1->>Form1: 清空所有输入字段
    Note over Form1: textBox1 = "" (重车)<br/>textBox2 = "" (空车)<br/>textBox3 = "" (净重)<br/>textBox5 = "" (车牌号)

    Note over Form1,Server: ⚠️ 上传失败无任何提示<br/>⚠️ 未调用 DatabaseHelper 保存到本地<br/>⚠️ 未调用 PrintService 实际打印
```
