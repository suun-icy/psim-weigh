# Claude 开发规范

开发目标：
在保持一期功能完全兼容的前提下，逐步扩展二期能力。

开发原则：

1. 不允许修改已有业务逻辑，除非明确要求。

2. 不允许修改数据库字段名称。

3. 不允许修改串口通信协议。

4. 新功能必须采用模块化设计。

5. 每次开发仅完成一个功能点。

6. 每次提交必须包含：
   - 设计说明
   - 修改文件列表
   - 新增文件列表
   - 数据库变更（如有）
   - 测试方案
   - 回滚方案

7. 所有新增代码必须兼容：
   - C#
   - .NET Framework 4.7.2
   - WPF
   - Windows 7/10/11

8. 不得引入需要 .NET Core/.NET 5+ 的依赖。

9. 优先使用接口（Interface）实现模块解耦，避免业务层直接依赖第三方 SDK。

10. 新功能需保留手动模式，不得强制依赖硬件设备。即使未连接地磅或摄像头，软件也应能正常完成称重记录维护。
