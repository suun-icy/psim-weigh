# psim-weigh 三期功能规划

> 版本：v3.0
> 规划日期：2026-07-05
> 主题：**车牌识别 — 海康威视摄像头 + 通用摄像头**
> 一期/二期：已完成

---

## 一、三期目标

以「车牌识别」为核心，支持海康威视结构化摄像头和普通 USB/RTSP 摄像头的接入，实现车辆进出场时自动识别车牌号并回填到称重主界面。所有摄像头功能通过 Interface 解耦，保留手动输入模式，不强制依赖硬件。

## 二、功能清单与优先级

| 序号 | 功能模块 | 优先级 | 说明 |
|------|---------|--------|------|
| 3.1 | **摄像头服务接口** | P0 | 定义 ICameraService/ILPRService 接口，数据库建表 |
| 3.2 | **通用摄像头接入** | P0 | USB/RTSP 摄像头画面预览 + 拍照 + 车牌识别 |
| 3.3 | **海康威视 SDK 接入** | P1 | 对接 HCNetSDK，支持设备发现 + 画面预览 + ANPR 回调 |
| 3.4 | **车牌识别引擎** | P0 | OCR 识别实现 + 海康 ANPR 模式切换 |
| 3.5 | **摄像头管理界面** | P0 | 添加/编辑/预览/测试摄像头配置 |
| 3.6 | **主界面集成** | P1 | Form1 中自动抓拍 + 车牌回填 |

## 三、架构设计

```
Interfaces/
  ICameraService.cs      — 摄像头抽象（连接/断开/抓拍/预览流）
  ILPRService.cs         — 车牌识别抽象（识别图片→车牌号）

Services/
  GenericCameraService.cs — 通用摄像头（USB/RTSP via AForge.NET）
  HikvisionCameraService.cs — 海康威视 SDK 封装
  PlateRecognizer.cs      — 默认 OCR 识别引擎
  HikvisionAnprService.cs — 海康 ANPR 识别引擎

Models/
  CameraConfig.cs         — 摄像头配置实体

Database/
  Cameras 表              — 摄像头配置持久化

Forms/
  CameraForm.cs           — 摄像头管理 + 预览窗口
```

## 四、数据库设计

```sql
CREATE TABLE IF NOT EXISTS Cameras (
    Id          TEXT PRIMARY KEY,
    Name        TEXT NOT NULL,            -- 摄像头名称
    CameraType  TEXT NOT NULL,            -- Hikvision / Generic / USB
    IPAddress   TEXT,                     -- IP 地址
    Port        INTEGER DEFAULT 8000,     -- 端口
    Username    TEXT,                     -- 登录用户名
    Password    TEXT,                     -- 登录密码（Base64 存储）
    ChannelNo   INTEGER DEFAULT 1,       -- 通道号
    RTSPUrl     TEXT,                     -- RTSP 流地址（通用摄像头用）
    Resolution  TEXT DEFAULT '1920x1080', -- 分辨率
    IsEnabled   INTEGER DEFAULT 1,       -- 是否启用
    IsDefault   INTEGER DEFAULT 0,       -- 是否默认摄像头
    CreateTime  DATETIME DEFAULT CURRENT_TIMESTAMP,
    UpdateTime  DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

## 五、技术方案

| 场景 | 方案 |
|------|------|
| 通用 USB 摄像头 | AForge.NET (VideoCaptureDevice) 获取画面 → OpenCvSharp 处理 → OCR |
| 通用 RTSP 摄像头 | FFmpeg 解码 → 单帧抽图 → OCR 识别 |
| 海康 ISAPI 模式 | HTTP REST API 抓图 → OCR 识别 |
| 海康 SDK 模式 (ANPR) | HCNetSDK.NET 预览 + NET_DVR_Init + 布防回调 → 对接内置 ANPR 事件 |
| 手动模式 | 无摄像头时正常手动输入车牌，系统不报错 |

## 六、接口定义

```csharp
// 摄像头服务接口
public interface ICameraService
{
    event Action<Bitmap> FrameCaptured;     // 帧捕获事件
    bool Connect(CameraConfig config);       // 连接摄像头
    void Disconnect();                       // 断开
    Bitmap CaptureSnapshot();                // 抓拍当前帧
    bool IsConnected { get; }
    string ServiceName { get; }
}

// 车牌识别接口
public interface ILPRService
{
    event Action<string> PlateRecognized;    // 识别成功事件
    string Recognize(Bitmap image);          // 识别单张图片
    bool IsAvailable { get; }
    string EngineName { get; }
}
```

## 八、兼容性保证

- 所有摄像头功能通过 Interface 调用，Form1 不直接依赖任何 SDK
- 未连接摄像头时自动回退到手动输入
- 不修改已有称重/打印/查询逻辑
- 不修改已有数据库字段名
- AForge.NET / OpenCvSharp4 兼容 .NET Framework 4.7.2
- HCNetSDK 为海康威视官方 SDK，需单独安装
